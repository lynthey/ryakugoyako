# 略語夜行

スマホ1台で遊ぶ略語当てパーティーゲームです。駅名標に出る略語を、正式名称に戻して声で答えます。

## 遊び方

1. `index.html` をブラウザで開きます。
2. 乗客（プレイヤー）の名前、出題ジャンル、制限時間、ミスの上限、判定方式、BGM を選びます。
3. 「出発進行！」で開始します。同じ人がミスの上限に達したら終点で、その人に罰ゲームです。

## 音声判定を使うには

音声認識はマイクを使うため、https で配信されたページでしか動きません。

- GitHub Pages などの https サイトにこのフォルダを置き、Android の Chrome か iPhone の Safari で開きます。
- `file://` で直接開いた場合や、非対応のブラウザでは、自動で手動判定になります。

## BGM

- オリジナル曲：ゲーム内で生成する曲です。残り3秒でテンポが上がり、ミスすると止まります。
- 自分のファイル：端末内の音声ファイルを選んで流せます。ファイルは端末の中で読み込むだけで、送信されません。

## 問題の追加

設定画面の「オリジナル問題」に、1行1問で `略語=正式名称` と書きます。別の言い方も正解にしたいときは `|` で区切ります。

組み込みの問題は `index.html` の中の `const Q=[...]` にあります。形式は `["略語","正式名称|別解","ジャンル記号"]` です。

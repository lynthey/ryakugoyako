# 略語夜行

スマホ1台で遊ぶ略語当てパーティーゲームです。駅名標に出る略語を、正式名称に戻して声で答えます。

## 遊び方

1. `index.html` をブラウザで開きます。
2. 乗客（プレイヤー）の名前、出題ジャンル、テンポ（BPM）、ミスの上限、判定方式、サウンドを選びます。
3. 「出発進行！」で開始します。同じ人がミスの上限に達したら終点で、その人に罰ゲームです。

## リズムのルール

4拍子2小節（8拍）で1問です。拍は BGM の再生開始に合わせて数え、問題は必ず8拍の区切りから始まります。略語の読み上げは、各8拍の1拍目で始まります。

| 拍 | 内容 |
|---|---|
| 1〜4拍目 | 略語を読み上げます。マイクは常にオンですが、読み上げ中の音は判定に使わず、読み終わった瞬間から回答を受け付けます |
| 5〜6拍目 | 回答時間です |
| 7〜8拍目 | 締め切りです。8拍目が終わるまでに正解すると `ok1`（惜しい正解は `ok3`） |

延長はありません。拍がずれないよう、8拍目が終わった時点で時間切れです。何か答えていたら `ng1`、何も答えていなければ `ng2` を、BGMを止めてから鳴らします。

テンポの初期値は 144 BPM です。`bgm1.mp3` を解析した値で、最初の拍は再生開始から約 0.025 秒後です。別の曲に替えたときは、設定の「タップで測る」で合わせてください。

## 問題の読み上げ

設定の「問題の読み上げ」をオンにすると、端末に内蔵された音声合成で略語を読み上げます。読み上げが終わってから、制限時間と音声認識が始まります。

読み方を指定したい略語は、`index.html` の `const YOMI={...}` に `"略語":"よみかた"` の形で追加します。

## 診断表示（音声判定のとき）

プレイ画面の聞き取り欄に、次の3つを表示します。音声が入らないときの原因を切り分けるためのものです。

- MIC バー：マイクに入っている音の大きさです。声を出しても動かなければ、マイク自体に音が届いていません。
- 認識の状態：「動作中」「マイク受信中」「声を検出」「停止→再開（n回目）」「エラー：…」を表示します。
- 受付状態：「受付中」のときだけ、聞こえた内容を判定に使います。「読み上げ中（無視）」「待機」のときは判定しません。

MIC バーは、設定の「マイク入力バー（診断用）」で消せます。端末によっては、バー用のマイク取得と音声認識が同時にマイクを使うと、認識の調子が悪くなることがあります。その場合はバーを消してください。

## 音声判定を使うには

音声認識はマイクを使うため、https で配信されたページでしか動きません。

- GitHub Pages などの https サイトにこのフォルダを置き、Android の Chrome か iPhone の Safari で開きます。
- `file://` で直接開いた場合や、非対応のブラウザでは、自動で手動判定になります。

## サウンド

設定画面の「サウンド」で次の3つから選びます。

- sound フォルダの音源：`sound/` に置いた mp3 を使います。
  - `s1.mp3`：開始時のジングル。終わると続けて `bgm1.mp3` をループ再生します。
  - `ok1.mp3`：8拍目までに正解。`ok3.mp3`：8拍目までに惜しい正解（ほぼ一致）。`ok2.mp3` は現在使っていません。
  - `ng1.mp3`：何か答えたが正解しないまま時間切れ、または手動の×。
  - `ng2.mp3`：何も答えないまま時間切れ。
  - 時間切れのときは、BGMを止めてから鳴らします。
  - ミスのあとは「仕切り直して発車」で、鳴っている `ng1`・`ng2` を止めてから `s1.mp3` のジングルで再スタートします。
  - 見つからないファイルは、オリジナル音源で代わりに鳴らします。
- オリジナル音源：ゲーム内で生成する発車チャイムとBGMを使います。
- 効果音だけ：BGMなしで、オリジナルの効果音だけを鳴らします。

`sound/` フォルダは `.gitignore` で除外しています。権利を持たない音源を公開リポジトリに含めないでください。音源が無い環境（GitHub Pages など）では、自動でオリジナル音源になります。

## 問題の追加

設定画面の「オリジナル問題」に、1行1問で `略語=正式名称` と書きます。別の言い方も正解にしたいときは `|` で区切ります。

組み込みの問題は `index.html` の中の `const Q=[...]` にあります。形式は `["略語","正式名称|別解","ジャンル記号"]` です。
